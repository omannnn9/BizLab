Q4 Assembly Line Retrofit — Safety Checklist

This checklist governs pre-commissioning sign-off for the Line 3 retrofit. Every item requires initials from the assigned safety lead before the line returns to production.

Pre-commissioning

  • Lockout-tagout verification on all six robotic cells
  • Emergency stop circuit continuity test
  • Guard interlock calibration — sensor array, Line 3
  • Third-party fire-suppression inspection sign-off

Calibration script

Run the following against the sensor controller before enabling automatic mode:

// calibrate-sensor-array.js
const array = connect('line3-ctrl');
array.setThreshold(0.42);
array.runSelfTest();

Once the self-test passes with zero faults, notify the shift supervisor and update this document's status to Approved.
